## 一、方案修订说明

本版根据已有论文调研、无序抓取 V2.2
方案、机械臂工程审计，以及本次确认的硬件和验证边界收敛而成。

**本课题不是"只做仿真"的研究。**
已经开展过有序抓取真机测试，机械臂能够执行既有有序抓取流程。这些工作是本课题的重要工程基础，可以复用已有视觉、控制、夹爪调节和机器人执行经验。无序抓取是在此基础上，进一步研究复杂场景中的实例区分、6D
抓取候选评价、运动可执行性和连续抓取闭环。

本版明确调整：

1.  将已有有序抓取真机成果列为前期基础，不重复计算为无序抓取待完成任务。
2.  真实 D435i、Dobot CR10A、气动平行双指夹爪、MuJoCo 均纳入研究体系。
3.  MuJoCo 用于算法开发、物理接触分析、碰撞预检和可重复对照实验；CR10A
    真机用于验证真实视觉、实际夹持、提升、撤离和连续抓取。
4.  真机验证是明确研究目标，不是可有可无的附加项；但采用分级放行，避免未经核验直接执行复杂动作。
5.  只有经过对照实验验证的方法才作为创新贡献；系统集成和已有真机基础不包装成新算法。

### 3.2 必须保留的事实边界

1.  有序抓取真机通过，说明已有机器人执行基础，但不等于无序抓取已经通过真机验证。
2.  D435i 单目标 XYZ
    验证，不等于多物体遮挡场景下实例点云和抓取位姿均已达标。
3.  已有夹爪调节功能，不自动证明原有末端执行器与论文确定的平行双指夹爪完全一致。
4.  既有工程审计曾指出旧控制链路存在吸盘气路/IO 逻辑，且
    TCP、持物反馈、避障和执行闭环仍有核实或补齐项。因此必须核实当前平行夹爪的硬件和接口，不能直接沿用旧接口假设。
5.  MuJoCo 物理抓取结果和 CR10A 真机抓取结果必须分开统计。

## 四、论文核心研究问题

### 4.1 总研究问题

在料箱内同类圆柱形物体存在姿态变化、相互交叉、堆叠和局部遮挡的情况下，如何利用真实
RGB-D
感知生成抓取候选，并结合平行双指夹爪的接触几何约束和机械臂运动可执行性，选择并执行可靠的无序抓取动作？

### 4.2 核心问题一：抓取候选的双侧接触几何可靠性

学习式 6D
抓取网络可以生成多个候选，但网络分数不必然代表真实平行夹爪左右手指都具有可靠的接触几何支撑。

重点研究：

-   如何将抓取候选与正确目标实例关联；
-   如何根据候选位姿和夹爪几何构建左右手指预计接触区域；
-   如何分别评价左右接触区域的深度有效率、局部几何连续性、法向稳定性和几何拟合质量；
-   如何评价双侧接触位置与目标圆柱几何、夹持宽度之间的一致性；
-   如何利用评价结果筛选、拒绝或重排序抓取候选。

### 4.3 辅助问题二：规划失败反馈与候选修正

视觉候选通过几何评价后，仍可能出现 IK
无解、接近碰撞、提升碰撞或撤离路径不可行等情况。

重点研究：

-   如何将候选转化为预抓取、接近、闭合、提升和撤离任务位姿；
-   如何利用 CR10A 运动学、关节限位和碰撞检查验证可执行性；
-   如何结构化记录规划失败原因；
-   如何在有限范围内调整手腕姿态、接近方向或预抓取偏移；
-   修正后如何重新执行完整安全检查。

这项研究暂定位为辅助贡献。只有在与"直接切换下一个候选"相比取得独立、可复现的改善后，才将其提升为第二个正式创新点。

## 六、创新点收敛方案

### 6.1 主创新：目标实例约束的双侧接触几何可信度评价

**拟解决问题：**
在易拉罐交叉、堆叠和局部遮挡情况下，学习式抓取候选可能具有较高网络分数，但左右手指预计接触区域不一定都具有可靠几何支撑。

**建议方法：**

1.  将抓取候选与实例分割结果关联，确认候选对应的目标实例。
2.  根据候选位姿、夹爪开口和手指几何建立左右预计接触区域。
3.  提取左右区域的深度有效率、局部连续性、法向稳定性、圆柱拟合残差和边界距离等特征。
4.  分别计算左右接触区域的几何质量。
5.  建立双侧接触几何一致性评价。
6.  将评价结果用于候选过滤或重排序。

先建立可解释的规则评分，不急于训练 MLP 或局部点云网络。

建议消融：

  组别   方法                        目的
  ------ --------------------------- --------------------------
  V0     原始学习式抓取候选          建立基线
  V1     V0 + 目标实例约束           验证实例约束
  V2     V1 + 左右接触区域几何评价   验证双侧几何评价
  V3     V2 + 双侧几何一致性         验证一致性评价的独立贡献

主要指标：

-   左右接触区域几何有效率；
-   双侧几何一致性；
-   目标实例接触点命中率；
-   候选有效率；
-   错误实例接触比例；
-   深度缺损情况下的正确拒抓率；
-   MuJoCo 物理抓取成功率；
-   CR10A 真机抓取成功率。

**创新性边界：** 实例分割、GraspNet
调用、深度有效率阈值和简单加权排序本身不能直接称为创新。需要证明面向平行双指夹爪的双侧接触几何评价能够提供现有网络分数没有表达的信息，并且这种信息确实改善抓取结果。

### 6.2 辅助贡献：规划失败反馈驱动的候选局部修正

研究范围限定为：

-   IK 无解；
-   接近阶段碰撞；
-   提升阶段碰撞；
-   撤离阶段碰撞。

局部修正变量优先限定为：

-   手腕姿态；
-   接近方向；
-   预抓取偏移。

必须与以下基线比较：

-   最高网络分数候选直接规划；
-   Top-K 候选依次规划；
-   Top-K + 失败分类；
-   Top-K + 失败分类 + 局部修正。

主要指标：

-   IK 成功率；
-   完整路径规划成功率；
-   规划耗时 P50/P95；
-   最小安全间隙；
-   重新规划成功率；
-   最终仿真和真机抓取成功率。

如果局部修正没有相对于直接切换候选取得稳定改善，就将其作为系统工程策略和实验分析，不强行包装为第二项算法创新。

### 6.3 不建议同时增加的研究内容

-   自适应安全裕量和完整不确定性传播；
-   端到端抓取策略学习；
-   新的 6D 抓取网络训练；
-   多网络融合；
-   主动推抓；
-   复杂力控和滑移控制；
-   混合物体类别和透明物体。

这些内容会明显增加数据、算法、硬件和实验依赖。

## 七、真实视觉、仿真和真机的验证关系

本课题必须同时保留真实视觉、MuJoCo 和 CR10A
真机验证，三者承担不同任务，不能相互替代。

### 7.1 真实视觉实验

使用真实 D435i 采集实际料箱场景，保存：

-   RGB 图像；
-   深度图；
-   相机内参和深度比例；
-   实例 Mask 与 Instance ID；
-   目标点云和完整场景点云；
-   抓取候选及其坐标变换；
-   候选评价特征和拒绝原因。

真实视觉数据是算法输入，不使用完全随机的仿真图像代替真实相机数据。

### 7.2 MuJoCo 物理仿真实验

建立与实际设备相对应的模型：

-   CR10A 机械臂；
-   气动平行双指夹爪；
-   真实夹爪手指、掌部和 TCP；
-   蓝色料箱；
-   直接铺在料箱底部的薄泡沫板；
-   与真实易拉罐尺寸和质量尽可能一致的物体模型。

仿真验证：

1.  IK 是否可解；
2.  接近路径是否碰撞；
3.  夹爪闭合时是否形成合理双侧接触；
4.  提升时目标是否稳定随动；
5.  撤离时是否与邻物和箱壁碰撞；
6.  放置是否完成；
7.  连续仿真抓取后场景状态是否正确更新。

真实场景驱动仿真时，必须将真实物体布局映射到对应虚拟场景。MuJoCo
自行随机生成的场景应标记为独立仿真数据，不能声称来自 D435i 真实观测。

### 7.3 CR10A 真机实验

真机是本课题明确的最终验证平台，不是可有可无的选项。

  阶段   真机实验                 验收重点
  ------ ------------------------ ----------------------------------------------
  R0     有序抓取既有成果整理     整理真机程序、设备配置、视频和实验记录
  R1     CR10A 空载低速动作       坐标、TCP、关节方向、运动接口和急停
  R2     平行夹爪开合与反馈       开口范围、气路、闭合时间、压力和夹持反馈
  R3     单个易拉罐抓取           接近、闭合、提升、撤离和放置
  R4     多个易拉罐静态无序抓取   多实例选择、邻物碰撞和抓取成功率
  R5     连续无序抓取             每次执行后重新采集、更新场景、避免旧位姿误用

真机动作必须逐级放行，具备现场人员确认、急停和碰撞保护。仿真通过不能直接作为真实设备运动授权。

### 7.4 真机实验统计要求

每类场景使用多个独立摆放状态，分别记录：

-   视觉检测成功次数；
-   候选生成数量；
-   候选通过几何评价数量；
-   IK 成功次数；
-   完整路径规划成功次数；
-   真实夹持成功次数；
-   试提成功次数；
-   成功放置次数；
-   单次作业时间；
-   失败类型和恢复结果。

抓取成功率必须明确分母。例如：

-   候选执行成功率 = 成功抓取次数 / 实际执行抓取次数；
-   端到端成功率 = 成功放置次数 / 完整任务尝试次数。

不能只统计成功视频，也不能将仿真成功次数和真机成功次数混合计算。

### 8.2 工作量判断

当前方案仍是一项中等偏重的硕士研究课题，但不再是要求从零开发完整机械臂产品的超大型工程。

工作量主要集中在：

1.  一个学习式 6D 抓取基线的稳定复现与真实夹爪适配；
2.  双侧接触几何评价方法设计和实验；
3.  CR10A、平行夹爪、MuJoCo 的一致性建模与运动验证；
4.  真实料箱场景中的单物体、多物体和连续抓取实验；
5.  规划失败反馈的有限研究和对照实验。

有序抓取真机成果能够降低机器人基础控制和平台搭建成本，但不能直接替代无序抓取中的多实例感知、抓取候选评价、邻物碰撞和场景更新研究。

### 8.3 推荐工作量方案

**一个核心创新 + 一个辅助贡献 + 真实系统验证。**

-   核心创新：双侧接触几何可信度评价。
-   辅助贡献：规划失败反馈驱动的有限候选修正。
-   必须验证：真实 D435i、MuJoCo 物理仿真、CR10A
    真机单物体和多物体抓取。
-   最终目标：真实视觉驱动的连续无序抓取。

不要求所有模块都提出新算法，但必须确保论文核心方法有独立对照和消融证据。

## 十二、最终结论

本课题不应被定位为"只做仿真的无序抓取算法验证"。已有有序抓取真机工作是重要工程基础，CR10A
真机抓取也是本课题明确的最终验证目标。

真正需要收敛的是研究内容，而不是取消实物实验：

-   视觉分割、点云、坐标转换和既有机械臂控制作为基础能力复用；
-   PCA 和一个学习式抓取模型构成候选生成基线；
-   双侧接触几何可信度评价作为论文核心创新；
-   规划失败反馈作为有条件的辅助贡献；
-   MuJoCo 用于物理仿真、算法调试和可重复实验；
-   CR10A 真机用于验证真实夹持、提升、撤离、多物体选择和连续无序抓取。

**最终目标是完成一套真实视觉驱动、经过仿真与真机双重验证的料箱无序抓取方法，而不是把每个工程模块都做成一项独立创新。**

本方案作为论文研究范围
V3.0。后续新增任务必须回答三个问题：是否直接服务于核心研究问题、是否有独立实验指标、是否会显著增加毕业风险。不能回答这三个问题的扩展任务，默认不进入主线。
