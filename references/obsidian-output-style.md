# Obsidian Research Output Style

本规范供 robotics-thesis-research-pipeline 生成论文资料包使用，目标是让 Obsidian 内部链接真正可用、结构清楚、视觉克制，并兼容未启用 CSS 的普通 Markdown 阅读器。

## 1. 页面结构

- 每份资料包有唯一 00_阅读入口.md。
- 论文文件名使用真实论文标题，稳定 ID 放入 YAML paper_id 与 aliases。
- 单篇论文将结论卡、深度精读、证据索引、标准化记录整合到一篇笔记，保留全部实质内容。
- 单篇笔记导航应同时包含本篇章节和回到专题的链接。
- 文献目录按优先级分组，优先使用分组列表，不强制使用宽表格。

## 2. 链接语法

### 正文列表

~~~md
- [[论文真实标题|打开论文精读]]
- [[#方法链路重建|方法链路]]
- [[../00_阅读入口|返回资料包入口]]
~~~

### Markdown 表格

表格内不要写 [[目标|显示文字]]，因为 | 会被 Markdown 解析为列分隔符。统一使用：

~~~md
| 论文 | 作者 |
|---|---|
| [论文标题](<02_单篇论文/论文标题.md>) | 作者姓名 |
~~~

### 相对路径规则

- 路径以当前 Markdown 文件所在目录为起点。
- 根目录入口到子目录：02_单篇论文/论文标题.md。
- 子目录回到根目录：../00_阅读入口.md。
- 含空格路径使用尖括号包裹。
- 图片、PDF页面、JSON、CSV、脚本必须指向实际存在的文件。

## 3. 标题与锚点

- 最高标题 ##，主题 ###，子主题 ####。
- 同一文件不使用重复标题；历史重复内容可保留，但必须标注“历史归档副本”并使用唯一标题。
- 标题链接必须引用真实标题，不猜测锚点 slug。
- 修改标题后全库搜索并更新所有引用。

## 4. Callout 与颜色语义

| 类型 | 用途 |
|---|---|
| [!abstract] | 研究对象、论文摘要、核心定位 |
| [!tip] | 阅读顺序、操作提示 |
| [!success] | 有证据支持的已验证结果 |
| [!warning] | 未核验、证据不足、统计口径待确认 |
| [!danger] | 阻塞、关键风险、不可接受的证据缺口 |
| [!example] | 典型案例、失败场景、对照示例 |

不要让所有内容都进入 Callout。颜色只辅助表达语义，必须同时保留文字状态。

## 5. CSS snippet

可选样式位于 templates/obsidian/thesis-research-theme.css。复制到 Vault 的 .obsidian/snippets/ 并在 Obsidian 设置中启用。CSS 使用 thesis-paper 与 thesis-hub 两个 scoped class，不全局更改用户主题；禁用 CSS 后文档仍可正常阅读。

## 6. 强制交付检查

- [ ] 所有 Wiki 链接目标文件存在。
- [ ] 所有 Markdown 相对链接目标存在。
- [ ] 所有标题锚点存在且不重复。
- [ ] 所有图片/附件嵌入路径存在。
- [ ] Markdown 表格内没有带竖线的 Wiki 链接。
- [ ] 子目录笔记可返回入口。
- [ ] 单篇笔记可跳转到横向比较、课题适配和创新审查。
- [ ] 深色/浅色主题均检查可读性；无 CSS 时仍可读。
- [ ] 论文内容没有因合并、排版或美化而删减。
