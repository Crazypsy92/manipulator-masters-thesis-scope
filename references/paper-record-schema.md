# Standardized Paper Record Schema

> 本文件定义 Stage 2 → Stage 3 的唯一标准交接格式。每篇论文一份。字段无证据时写 `未报告`、`无法确认` 或 `不适用`，不得猜测。

## 1. Bibliographic identity
- Paper ID:
- Title:
- Authors:
- Year:
- Venue / Institution:
- DOI:
- Document type:
- PDF filename / page count:
- Readability / missing material:

## 2. Research problem (WHY)
- Application scenario:
- Target object / task:
- Main constraints:
- Research gap claimed by authors:
- Scientific question / hypothesis:
- Prior methods and limitations:

## 3. Method reconstruction (HOW)
- Method family:
- Input modality:
- Input representation:
- Preprocessing:
- Main modules:
- Key equations / objective:
- Training required:
- Dataset / labels:
- Pretrained weights:
- Inference pipeline:
- Output representation:
- Coordinate frame / units:
- Downstream interface:
- Compute / runtime:
- Code / data availability:
- Reproduction blockers:

## 4. Experimental evidence (WHAT)
- Dataset and split:
- Test scenarios:
- Baselines:
- Metrics and exact definitions:
- Main numerical results:
- Ablations:
- Simulation platform and role:
- Physical robot / gripper / sensor:
- Real-world validation:
- Trial counts / denominators:
- Failure cases:
- Author-stated limitations:

## 5. Figures, tables and software audit
- Key figures (number, title, page, purpose):
- Key tables (number, title, page, purpose):
- Curves / visualizations:
- Software and category:
- Actual use / mention only / unclear:
- Software version:
- Evidence locations:

## 6. Critical appraisal
- Strongest evidence:
- Weakest evidence:
- Claim-evidence mismatch:
- Confounds / protocol concerns:
- Generalization boundary:
- Reviewer questions:
- Confidence level:

## 7. Research reuse
- Reproducible as-is:
- Reusable with modification:
- Conceptual reference only:
- Not suitable:
- Potential research gap:
- Relevance to user's project:
- Evidence locations:
